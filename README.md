## 🌟 核心功能概览

全新 Material 3 架构界面，所有核心操作均在应用内沉浸式完成，告别繁琐的文件管理：

- **自定义会员级别**：在付款码页面显示为钻石会员或者是伪装成大众会员均可。
- **全局主题替换**：不仅限付款页面，支持一键替换、导出支付宝全局主题及组件外观。
- **自定义付款码**：灵活开启/关闭个性化付款码皮肤，多个皮肤同时启用时将随机展示。
- **内置网页编辑器**：通过手机或电脑浏览器访问内置服务，实时可视化修改皮肤与主题资源。
- **极简管理**：一键下载基础样例主题/皮肤，或直接导入本地 Zip 包。

## 🚀 快速上手

1. 在 LSPosed 中启用本模块，并勾选作用域 **支付宝**。
2. **重启支付宝**进程以激活模块注入。
3. 打开本应用，在底部导航栏选择所需功能版块：
   - **付款码皮肤** / **主题**：点击右下角按钮直接浏览在线图库或导入 Zip。
4. 勾选需要启用的皮肤或更换的主题，应用会自动配置缓存更新。
5. 再次进入支付宝对应界面，即可享受定制化效果！

## 🎨 强大的内置修改器

告别复杂的手动打包与解包，使用内置**皮肤修改器**轻松制作专属外观：

1. 切换至“皮肤修改器”标签页并启动服务。
2. 使用修改器时，建议允许后台通知权限并取消电池优化，以保持修改器稳定后台运行。
3. 在同一局域网下的电脑（或本机浏览器）输入提示的网址即可进行可视化编辑，替换图片、调节颜色、裁剪一气呵成。

## 🧩 深度定制：支付宝全局主题

支付宝不仅限于原版配色！在**主题**标签页下，您可以：
- **在线样例主题库**：一键拉取财富黑卡样例主题模版。
- **提取与备份**：将支付宝当前正在使用的官方主题导出至应用内备份。更强大的是，您可以将任意已导出主题内包含的**付款码皮肤单独提取出来**，它们会作为独立的皮肤添加到“付款码皮肤”列表中。您可以从多个不同主题中提取出多个付款码皮肤，独立管理并支持同时启用随机展示。
- **即时替换**：在应用内选中主题，随后打开支付宝付款码页面即可自动触发全局替换。*(需确保支付宝内至少正使用着一款官方主题)*

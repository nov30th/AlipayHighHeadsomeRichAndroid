# 💎 支付宝装X模块

![GitHub stars](https://img.shields.io/github/stars/nov30th/AlipayHighHeadsomeRichAndroid?style=social)
![License](https://img.shields.io/badge/License-Apache%202.0-blue.svg)

> 专业级 Xposed / LSPosed 框架模块，为支付宝付款码界面提供黑色钻石会员级视觉效果与完全自定义的个性化皮肤。

*本模块仅通过 LSPosed 官方渠道发布，通过其他途径获取可能存在安全风险，请谨慎评估。*

## 📱 应用概览

全新 Material 3 界面，所有操作均在应用内完成，无需手动创建任何文件或文件夹：

- **付款皮肤总开关**：一键启用 / 暂时关闭付款码皮肤替换。
- **添加皮肤**（右下角 FAB）：从本地导入 Zip，或从 Github 下载作者上传的几个样式。
- **主题管理**： 能够导出，替换在使用的各种主题（包括出行，小组件等）
- **皮肤卡片**：点击开关勾选要使用的皮肤；点击「更多」可导出为 Zip 或删除该皮肤。
- **顶部菜单**：更新缓存、导出支付宝内置皮肤、清空缓存（通常不需要手动操作）。
- **自动缓存更新**：选中或切换皮肤时会自动计划缓存更新，下次进入付款码界面即可生效。

## 🚀 快速上手

1. 安装 APK 并在 LSPosed 中启用本模块，作用域勾选支付宝。
2. 重启支付宝一次。
3. 打开本应用，点击右下角 **添加皮肤**：
   - **导入本地 Zip**：选择已有的皮肤压缩包。
   - **从 Github 下载更多**：在线浏览并下载基础皮肤。
4. 在皮肤列表中打开开关勾选喜欢的皮肤，再确认顶部 **皮肤总开关** 已开启。
5. 进入支付宝付款码界面即可看到效果。

> 想要导出当前账号下发的官方内置皮肤？打开顶部菜单 → **导出内置皮肤**，下次进入付款码时会自动写入皮肤库。

## 🎨 自定义皮肤

每个皮肤是一个目录，包含背景图、Logo、遮罩等资源。建议使用应用提供的导出功能获得一份模板，然后替换其中的图片资源，最后用 Zip 打包后通过 **添加皮肤 → 导入本地 Zip** 重新导入。或者直接放入 skins 文件夹（`[SD卡根目录]/Android/media/com.eg.android.AlipayGphone/000_HOHO_ALIPAY_SKIN/skins/`）并手动点击刷新缓存。

替换皮肤目录中的 `background_2x1.png` 即可自定义付款码背景，建议使用与设备分辨率匹配的图片：

<img src="https://raw.githubusercontent.com/nov30th/AlipayHighHeadsomeRichAndroid/master/images/ps_bg.png" height="400" alt="背景设计示例" />

导入并启用后，进入支付宝付款码界面即可看到效果：

<img src="https://raw.githubusercontent.com/nov30th/AlipayHighHeadsomeRichAndroid/master/images/final_code.png" height="400" alt="定制效果展示" />

> ⚠️ 启用自定义皮肤不会修改账号数据或云端设置，所有更改仅在本地设备生效。
>
> ⚠️ 当存在多个启用的皮肤时，系统会在每次展示付款码时随机选择其中之一显示。
>
> ⚠️ 下载的在线皮肤仅作者上传的内容，由于第三方皮肤可能涉及的版权问题，因此不会包含。

## 🧩 支付宝主题

新版本增加了 **主题** 标签页，用于管理支付宝 App 主题，不只限于付款码界面，现在可以完全自定义：

- **导出当前主题**：点击后会创建导出请求，请重新打开支付宝。模块会把当前账号已下发的主题复制到 `themes/` 文件夹。
- **在线主题下载**：在主题标签页右下角点击 **在线主题** FAB，从 Github 下载作者整理的样例主题。
- **替换主题**：在主题卡片上点击 **替换**，模块会创建一次性替换请求；请重新打开支付宝，替换完成后请求标记会自动清除。
- **Zip / 删除**：主题卡片支持导出为 Zip，也可以删除本地已导出的主题。

注意：如果要替换主题，支付宝内必须已经启用一个主题。如果没有启用主题，替换主题无法工作。
